# 가상 스트림덱

들고 있는 폰을 PC 컨트롤 패널로.

![가상 스트림덱 시연](https://github.com/im-dullin/Stream-Deck-Mobile/raw/main/docs/demo.gif)

---

Elgato Stream Deck은 정말 잘 만든 제품이죠. 다만 가격이 부담스럽고, 책상 한자리도 차지하고, 버튼 개수도 정해져 있습니다. 그런데 우리는 이미 매일 손에 들고 다니는 고해상도 터치 화면이 있어요. 바로 스마트폰입니다.

가상 스트림덱은 그 스마트폰을 PC 조작용 데크로 바꿔줍니다. 두 기기가 같은 와이파이에 있다면, 처음 한 번만 페어링하고 PC에서 승인 한 번 눌러주세요. 그 뒤로는 폰을 켜기만 하면 자동으로 다시 연결됩니다.

---

## 한 버튼, 여러 동작

자주 쓰는 앱과 URL을 그리드 버튼에 연결해 두면 한 번의 탭으로 실행됩니다. 한 버튼에 최대 10개의 동작을 순서대로 묶을 수도 있어서, "작업 시작" 한 번에 Slack과 Notion이 함께 켜지고 로파이 플레이리스트가 자동으로 재생되도록 만들 수 있습니다.

## 필요한 것

PC 한 대, 폰 한 대, 그리고 같은 와이파이. 그게 전부입니다.

클라우드 서버도, 회원가입도, 구독 결제도 없습니다. 모든 데이터는 두 기기 사이에서만 오갑니다.

---

## 설치

### macOS

1. [Releases](https://github.com/im-dullin/Stream-Deck-Mobile/releases) 에서 **`.dmg`** 파일을 받습니다. (Apple Silicon과 Intel 모두 지원하는 Universal 바이너리예요.)
2. `.dmg` 를 더블클릭하고, 열린 창에서 앱 아이콘을 Applications 폴더로 드래그하세요.
3. Spotlight(`⌘Space`) 로 "가상 스트림덱" 을 검색해 실행합니다.

> 처음 실행할 때 "확인되지 않은 개발자" 경고가 뜨면, **시스템 설정 → 개인정보 보호 및 보안** 으로 들어가 아래쪽에 표시되는 "그래도 열기" 를 눌러주세요.

### Windows

1. [Releases](https://github.com/im-dullin/Stream-Deck-Mobile/releases) 에서 **`.msi`** 파일을 받습니다. (`ko-KR` 이 붙은 한국어 인스톨러)
2. 더블클릭한 뒤 설치 마법사의 Next → Install → Finish 순으로 진행하세요.
3. 시작 메뉴에서 "가상 스트림덱" 을 찾아 실행합니다.

> "Windows의 PC 보호" 화면이 뜨면 **추가 정보 → 실행** 을 눌러주세요. 코드 사이닝을 하지 않은 오픈소스 소프트웨어에서 흔히 거치는 단계입니다.

### 첫 실행 (공통)

방화벽이 네트워크 접근을 허용할지 물어봅니다. **개인 네트워크** 만 체크하고 허용을 눌러주세요. 그러면 작은 창이 뜨고, 그 안에 PC의 호스트 주소와 포트가 표시됩니다.

---

## 폰에서 연결

1. 먼저 PC의 IP 주소를 확인하세요.
   - macOS — 시스템 설정 → 네트워크 → Wi-Fi → 세부 사항 → IP 주소
   - Windows — `cmd` 창에서 `ipconfig` 를 실행하고 "IPv4 주소" 항목을 확인
2. 폰 브라우저(Safari 또는 Chrome) 주소창에 `http://<위에서 확인한 IP>:8090` 을 입력합니다.
3. 페어링 화면이 뜨면 같은 IP와 포트 번호(`41234`) 를 넣고 **페어링 요청** 을 누르세요.
4. PC 화면 상단에 요청 배너가 나타납니다. **승인** 을 클릭하세요.
5. 폰 화면이 자동으로 데크로 바뀌면 끝입니다.

폰 브라우저의 "홈 화면에 추가" 를 누르면 일반 앱처럼 보입니다.
&nbsp;&nbsp;&nbsp;&nbsp;Safari — 공유 버튼 → 홈 화면에 추가
&nbsp;&nbsp;&nbsp;&nbsp;Chrome — `⋮` → 앱 설치
홈 화면 앱은 브라우저와 저장 공간이 따로라서 처음 한 번만 다시 페어링해 주면, 그 뒤로는 자동으로 다시 연결됩니다.

---

## 버튼 설정

PC 화면에서 비어 있는 셀을 클릭하면 오른쪽에 인스펙터가 열립니다.

&nbsp;&nbsp;**`+ 앱`** &nbsp;·&nbsp; 설치된 앱을 아이콘과 함께 골라 추가
&nbsp;&nbsp;**`+ URL`** &nbsp;·&nbsp; 주소 입력 (유튜브 플레이리스트는 자동 재생됩니다)

한 셀에 최대 10개까지 동작을 담을 수 있고, 폰에서 그 셀을 한 번 탭하면 순서대로 모두 실행됩니다. 라벨도 자유롭게 바꿀 수 있는데, 수정 사항은 폰에 곧바로 반영됩니다.

       ┌──────────────────────┐        ┌──────────────────────────┐
       │   모바일              │        │   PC 에이전트             │
       │   Flutter Web        │        │   Tauri 2 (Rust + React) │
       │                      │        │                          │
       │   그리드·페어링       │◄──WS──►│   토큰 인증·액션 실행      │
       │                      │        │                          │
       │                      │◄─HTTP──│   모바일 웹 번들 호스팅   │
       └──────────────────────┘        └──────────────────────────┘

PC 에이전트가 모바일 웹 페이지를 직접 호스팅합니다. 폰에는 따로 설치되는 게 없어요. 그저 브라우저로 URL을 여는 것뿐입니다.

&nbsp;&nbsp;프로토콜&nbsp;&nbsp;·&nbsp;&nbsp;JSON over WebSocket
&nbsp;&nbsp;인증&nbsp;&nbsp;·&nbsp;&nbsp;기기마다 다른 UUID 토큰, PC에서 한 번 승인
&nbsp;&nbsp;범위&nbsp;&nbsp;·&nbsp;&nbsp;LAN 한정

## 설계 메모

폰에 앱을 깔지 않는 건 의도된 선택입니다. 앱스토어 심사도, 사이드로드 과정도 없어요. URL 하나만 있으면 어떤 OS에서도 똑같이 돌아갑니다.

한 번 발급된 페어링 토큰은 계속 유지됩니다. 두 번 다시 묻지 않아요.

한 버튼은 곧 하나의 작은 자동화입니다. 이 패턴 위에 매크로, 크롤링, 카드뉴스 생성 같은 작업을 자연스럽게 얹을 수 있습니다.
